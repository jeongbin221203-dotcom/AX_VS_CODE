# 컴활 필기 문제 형식

`content/written/<과목>_<번호>.json` (예: `computer_1.json`, `spreadsheet_2.json`, `database_1.json`). 파일마다 50문항 안팎.

```json
{"subject": "computer", "questions": [
 {"id": "pc-0001", "levels": ["c2", "c1"], "topic": "운영체제", "q": "문제 글", "options": ["보기1", "보기2", "보기3", "보기4"], "answer": 0, "explain": "해설"},
 ...
]}
```

- `subject`: `computer`(컴퓨터 일반) · `spreadsheet`(스프레드시트 일반) · `database`(데이터베이스 일반, 1급만).
- `id`: 과목 머리글자 + 4자리 — `pc-` · `ss-` · `db-`. 겹치면 안 됨.
- `levels`: 이 문제가 나올 수 있는 급. 2급 범위면 `["c2", "c1"]`, 1급에만 나오는 깊은 내용이면 `["c1"]`. 데이터베이스는 늘 `["c1"]`.
- `topic`: 아래 주제 이름 중 하나(과목별 연습에서 주제로 묶음).
- `options`: 보기 4개, 번호(①·1.)는 붙이지 않는다(화면이 붙임). `answer` 는 0~3.
- `explain`: 왜 정답인지 + 틀린 보기가 왜 틀린지 한두 줄.
- 한 줄에 문제 하나(`json.dumps(q, ensure_ascii=False)`), 파일 첫 줄은 `{"subject": "...", "questions": [`.

## 주제(topic)
- 컴퓨터 일반: `운영체제`, `시스템 설정`, `하드웨어`, `소프트웨어`, `자료 표현`, `네트워크·인터넷`, `멀티미디어`, `정보 보안`, `최신 기술`
- 스프레드시트 일반: `환경·파일`, `입력·편집`, `서식`, `수식·함수`, `데이터 관리`, `데이터 분석`, `차트`, `출력`, `매크로·VBA`
- 데이터베이스 일반: `DB 개념`, `테이블`, `관계·키`, `쿼리·SQL`, `폼`, `보고서`, `매크로·모듈`

## 작성 기준
- 대한상공회의소 2024~2026 출제 기준(Windows 10/11, Microsoft 365·Office 2021 한국어판). 메뉴·단축키 이름은 실제 한국어 화면 그대로.
- 기출 문제를 그대로 옮기지 않고 같은 범위를 새 문장으로 쓴다.
- 정답은 하나만, 사실 확인이 된 내용만. 보기 길이·자세함을 고르게(가장 긴 보기가 정답인 비율 30% 이하), 정답 위치도 고르게.
- 검사: `python tools/validate_written.py`
