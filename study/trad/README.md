# 무역연습실 · 국제무역사 1급

VS Code에서 실행하는 **개인용 Flask 학습 웹**입니다. 제59~65회 기출 7회분과 공식 정답표를 담았습니다.

> 서버 없이 HTML만으로 돌아가는 같은 앱이 옆 폴더 [`../trad_study`](../trad_study)에 있습니다(같은 백업 파일 형식이라 기록을 서로 옮길 수 있습니다).

**내 학습 기록(풀이·메모·AI 해설)은 서버가 아니라 쓰는 브라우저에 저장됩니다.** 서버를 껐다 켜거나 온라인 서버가 잠들어도 기록은 그대로입니다. 대신 기록은 그 브라우저·기기에만 있으므로, 기기를 바꾸거나 브라우저 데이터를 지울 때는 `학습 기록 백업`·`복원`을 쓰세요.

## 바로 시작하기

필요한 것: **Python 3.10 이상**, VS Code, 웹브라우저. AI 기능을 사용할 때만 OpenAI API 키와 인터넷 연결이 필요합니다.

### Windows · VS Code

1. VS Code에서 이 폴더(`study/trad`)를 엽니다. `app.py`와 이 README가 바로 보이는 폴더입니다.
2. VS Code의 **터미널 → 새 터미널**을 엽니다.
3. 다음 명령을 한 줄씩 실행합니다.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

4. 브라우저에서 **http://127.0.0.1:5090** 을 엽니다.
5. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

가상환경 활성화 스크립트를 쓰지 않으므로 PowerShell 실행 정책을 바꿀 필요가 없습니다. Python 설치 시 `py` 실행기를 설치하지 않았다면 첫 명령의 `py -3` 대신 `python`을 사용하세요.

**간편 실행:** Python 설치 후 `start.bat`을 더블클릭해도 설치와 실행을 진행할 수 있습니다.

**F5 디버깅:** VS Code의 Python 확장을 설치하고, `Python: Select Interpreter`에서 `.venv`를 고른 뒤 F5 → `무역연습실 Flask 실행`을 선택합니다.

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

또는 `sh start.sh`로 실행할 수 있습니다. Linux에서 venv 관련 오류가 나면 해당 OS의 Python venv 패키지를 설치해 주세요.

### 5090번 포트가 사용 중일 때

기본 포트는 **5090**입니다(같은 PC의 다른 Flask 앱이 쓰는 5000번과 겹치지 않게). 다른 번호로 실행하려면:

```powershell
.\.venv\Scripts\python.exe app.py --port 5091
```

이 경우 http://127.0.0.1:5091 에 접속합니다. 환경변수 `TRADE_PORT`로도 바꿀 수 있습니다.

시험 화면은 첨부 PDF의 **원본 문항 영역을 이미지로 표시**합니다. 밑줄, 표, 영어 서신과 보기의 모양을 보존하며, 선택한 답은 화면 아래 ①~④ 버튼으로 기록합니다. `문제 텍스트로 보기`와 원본 PDF 링크도 있습니다.

### 타이머와 오답 처리

- 제한 시간은 개인 연습용 설정입니다. 공식 시험 시간이나 공식 CBT 화면을 그대로 복제한 서비스는 아닙니다.
- 제한 시간을 정한 시험은 창을 닫아도 시간이 흐릅니다. 종료 후 다시 열면 저장된 답안으로 채점합니다.
- 제출 전 답안과 정답표를 대조하는 작업은 하지 않습니다. 결과에서 공식 정답을 보여 줍니다.
- 오답노트에는 **한 번이라도 틀린 문항**이 남습니다. 미응답 문항도 포함됩니다.
- `복습 완료`를 체크하면 복습할 목록에서 빠지고, 복습 완료 필터에서 다시 볼 수 있습니다.
- 나중에 같은 문항을 다시 틀리면 복습할 목록으로 돌아옵니다. 메모는 유지됩니다.
- 오답 재시험은 현재 선택한 과목의 미완료 오답을 최대 120문항까지 포함합니다.
- 점수는 정답 수 / 문항 수 × 100입니다. 공식 합격·과락 판정은 별도로 제공하지 않습니다.

## AI 키를 웹에서 입력하기

1. 웹 오른쪽 위의 **AI 연결하기**를 누릅니다.
2. 본인의 OpenAI API 키를 입력합니다.
3. 모델을 입력합니다. 기본값은 `gpt-4.1-mini`이며 계정에서 이용 가능한 이미지 입력 지원 모델로 바꿀 수 있습니다.
4. `연결 확인·사용`을 누릅니다. 짧은 실제 API 요청으로 연결을 확인합니다.

**`.env` 파일에 API 키를 넣을 필요가 없습니다.** 키는 브라우저 세션별로 Flask 서버의 메모리에만 임시 보관합니다. 데이터베이스, 코드, 쿠키, 브라우저 저장소, 백업 파일에는 기록하지 않습니다. 8시간 경과, 서버 종료, 또는 `연결 해제` 시 다시 입력해야 합니다. 브라우저 창을 닫는 것만으로 즉시 서버 메모리에서 삭제되는 것은 아니므로, 즉시 지우려면 연결 해제를 사용하세요.

채점·오답·메모는 AI 키 없이도 사용할 수 있습니다. **정답은 이미 포함되어 있고, 해설 840개를 미리 작성한 것은 아닙니다.** AI 연결 후 결과 또는 오답 화면에서 선택한 문항의 해설을 최초 열람 시 생성합니다. 생성된 해설은 다음에는 API 호출 없이 다시 읽습니다. 한 번에 840개를 자동 생성하지 않습니다.

연결 테스트, 챗봇 질문, 새 해설 생성은 API 호출 비용이 발생할 수 있습니다. 키 입력 화면에 이를 안내합니다. AI 요청에는 선택한 문제·공통 지문의 텍스트와 이미지, 질문 및 현재 대화의 최근 내용이 전송됩니다. 다른 메모나 다른 문항의 기록은 자동으로 보내지 않습니다.

AI 설명은 **공식 해설이 아닌 AI 초안**으로 표시합니다. 법령·규정의 개정 여부를 실시간 검색하지 않으며, 출제 당시 기준과 최신 기준을 혼동하지 않도록 안내합니다. 정답표와 어긋나거나 근거가 불명확한 설명은 원문을 확인해 주세요.

지원 API는 현재 **OpenAI Responses API**입니다. 다른 제공자의 API 주소를 직접 넣는 기능은 포함하지 않았습니다. 모델 접근 권한, API 잔액·한도, 인터넷 연결에 따라 연결이 실패할 수 있으며, 화면에 오류 안내가 표시됩니다. 챗봇 대화는 화면을 떠나거나 문항을 바꾸면 초기화되며, 해설과 메모는 저장됩니다.

공식 API 참고: [텍스트 생성](https://developers.openai.com/api/docs/guides/text), [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [API 키 관리](https://platform.openai.com/api-keys).

    style.css, fonts/       스타일·글꼴
  data/
    catalog.sqlite3         840문항과 공식 정답, 원문 영역 좌표

`catalog.sqlite3`는 읽기 전용입니다. 서버는 정답이 빠진 문제 목록(`/api/catalog`)과 원문 이미지를 주고, 채점할 때만 `/api/answers`로 공식 정답을 돌려줍니다. 시험 기록은 브라우저의 IndexedDB(`trade-study`)에 한 덩어리로 저장하고, 문제는 문제 ID(회차·과목·문항 번호를 합친 번호)로 연결합니다. 문제를 다른 순서로 풀어도 정답과 메모는 문제 ID를 기준으로 연결됩니다.

원본을 읽을 때 60회 무역규범 13번의 마침표 생략, 62회 무역계약 28번의 다른 들여쓰기, 다음 페이지까지 이어지는 공통 지문을 처리합니다. 원문 이미지는 필요할 때 렌더링하므로 실행에 PyMuPDF가 필요합니다.

시험지 PDF의 글자 층에는 문제 문장의 공백 문자가 빠져 있어 글만 뽑으면 '대외무역법령상무역거래의…'처럼 붙어 나옵니다. 변환할 때 글자 위치(간격)로 띄어쓰기를 되살립니다(`scripts/respace.py`, 공백 외 글자는 바뀌지 않음).

## 백업과 복원

1. 왼쪽의 `학습 기록 백업`을 누르면 `study-backup-날짜.json`이 다운로드됩니다.
2. 복원할 때는 왼쪽의 `학습 기록 복원`을 누르고 그 파일을 고른 뒤 `복원하기`를 누릅니다.
3. 이 브라우저의 풀이 기록·메모·AI 해설은 **백업 파일 내용으로 모두 바뀝니다**(합치기 아님). 지금 기록도 필요하면 먼저 백업하세요.

이 앱의 백업이 아니거나 손상된 파일, 이 앱의 문제와 맞지 않는 기록이 든 파일은 거부하고 기존 기록을 그대로 둡니다. 파일 크기는 50MB까지입니다. 예전 서버 저장 방식의 `study-backup.sqlite3`도 같은 `복원` 화면에서 올리면 브라우저 기록으로 바꿔 줍니다(서버에는 저장하지 않습니다).

백업에는 풀이 기록·메모·AI 해설이 들어가며 API 키는 들어가지 않습니다. 원본 문항과 PDF는 프로젝트의 `data` 폴더에 그대로 두면 됩니다.

**기록이 사라지는 경우:** 브라우저의 "사이트 데이터 삭제", 시크릿(비공개) 창, 다른 브라우저·기기로 옮김. 저장 공간이 부족할 때 브라우저가 지울 수도 있어 앱이 영구 저장을 요청하지만 보장되지는 않습니다. 중요한 기록은 가끔 백업해 두세요.

## 검증과 개발

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest tests -q
```

macOS/Linux에서는 `.venv/bin/python`으로 바꿔 실행하세요.

테스트는 서버(문제 목록에 정답 없음, 공식 정답 840개 일치, 원문 이미지, CSRF, API 키 비저장, 예전 백업 변환)와 브라우저 기록 저장소(28개 과목 시험의 전체 정답 채점, 미응답·오답, 답안 재개, 제출 후 수정 금지, 제한 시간, 메모·오답노트, 백업·복원, 동시 저장)를 확인합니다. 후자는 Node.js가 있으면 pytest가 `tests/store.test.js`를 함께 실행합니다(없으면 건너뜀). **자동 테스트에서 외부 AI 응답은 가짜 응답으로 대체**하므로 비용이 발생하지 않습니다. 개발 당시 실제 사용자의 API 키로 유료 API 호출을 수행하지 않았습니다.

문항 DB를 다시 만들려면 다음을 실행합니다. 원본 PDF는 그대로 두며, `data/catalog.sqlite3`만 재생성합니다. 일반 사용자는 실행할 필요가 없습니다. 문항 추가·형식 변경 시에는 변환 규칙 검토가 필요합니다.

```powershell
.\.venv\Scripts\python.exe scripts/build_catalog.py
```

## 온라인 배포 (Render)

GitHub 브랜치 `trad`(2026-10-10 이전 이름은 `trad_study`)를 Render 웹 서비스로 배포합니다.

| 항목 | 값 |
|---|---|
| Root Directory | `study/trad` |
| Build | `pip install -r requirements.txt` |
| Start | `gunicorn --workers 1 --threads 8 --timeout 120 --bind 0.0.0.0:$PORT wsgi:app` |
| Health Check | `/healthz` |
| 환경변수 | `TRADE_PROXY=1`(HTTPS 프록시 신뢰·보안 쿠키), `TRADE_SECRET_KEY`(세션 서명 키), `PYTHON_VERSION` |

- 워커는 **1개**여야 합니다. AI 키 보관함이 한 프로세스 메모리에 있습니다.
- 접속 주소(`RENDER_EXTERNAL_HOSTNAME`)는 허용 호스트에 자동으로 들어갑니다. 다른 도메인은 `TRADE_HOSTS=a.com,b.com`.
- 서버는 학습 기록을 갖지 않으므로 **무료 플랜이 잠들거나 재배포돼도 기록은 그대로**입니다(브라우저에 있음). 잠들었다 깨어날 때 첫 접속이 20초쯤 걸리고, 이때 AI 키 입력은 풀립니다.
- 서버 디스크가 필요 없습니다.
- 로그인이 없고 기록은 각자의 브라우저에 있어서, 주소를 아는 사람끼리 기록이 섞이거나 서로 볼 수 없습니다. 다만 AI 해설·챗봇은 입력한 키로 호출되므로 키는 본인 것만 넣으세요.

## 사용 범위

이 버전은 로그인 없는 **한 사람의 학습**을 전제로 하며, 로컬 실행은 `127.0.0.1`에서만 접속을 받습니다. 학습 기록은 각 브라우저가 따로 가지므로 여러 사람이 같은 서버를 써도 기록이 섞이지 않습니다. 기기 간 자동 동기화는 없습니다(백업·복원으로 옮김). 실전 연습의 "제출 전 AI 금지"와 정답 숨김은 화면에서 지키는 것이라, 개발자 도구를 쓰면 우회할 수 있습니다(스스로 공부하는 용도).

기출문제와 정답표의 출처는 사용자가 제공한 국제무역사 1급 시험 PDF이며, 그 권리는 원 저작권자에게 있습니다. Noto Sans KR 글꼴을 포함하며 글꼴 라이선스는 `static/fonts/OFL.txt`에 있습니다.
