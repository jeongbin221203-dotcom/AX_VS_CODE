# 주식 차트분석 프로그램 구현 계획

개인 학습·분석용 웹 프로그램. 투자 권유가 아니며, 화면에 "참고용, 투자 판단과 책임은 본인" 안내를 항상 표시한다.

## 1. 목표

- 종목을 검색하면 **캔들 차트 + 보조지표**를 바로 볼 수 있다.
- 내 관심종목을 모아 **한 화면에서 신호(골든크로스, RSI 과매도 등)** 를 확인한다.
- 조건을 걸어 **종목 스크리닝**(예: 20일선 돌파 + 거래량 2배)을 한다.
- 간단한 **백테스트**로 "이 전략이 과거에 어땠는지" 확인한다.
- 자동 매매는 **하지 않는다**(1단계 범위 밖). 분석·알림까지만.

## 2. 기술 스택 (기존 프로젝트와 같은 방식)

| 영역 | 선택 | 이유 |
|---|---|---|
| 서버 | Flask | 다른 프로젝트와 구조 통일 |
| 데이터 수집 | `FinanceDataReader`(국내·해외 일봉), `pykrx`(KRX 수급·시총), `yfinance`(해외·분봉 보조) | 무료, 키 불필요 |
| 지표 계산 | `pandas` + `ta`(또는 직접 구현) | 검증 쉬움 |
| 저장 | SQLite (`data/stock.db`) | 설치 불필요, 일봉 수백만 행도 충분 |
| 차트 | TradingView **Lightweight Charts** (`static/vendor`에 파일로 보관) | 캔들·거래량·다중 패널에 강하고 가벼움 |
| 화면 | Jinja 템플릿 + 순수 JS | CSP(인라인 스크립트 금지) 유지 |
| 테스트 | pytest | 지표·백테스트는 숫자 검증 필수 |

> 실시간 시세·주문이 필요해지면 증권사 API(한국투자증권 KIS Open API, 키움 등)를 2단계로 붙인다. 1단계는 **일봉 기준(장 마감 후 갱신)** 으로 시작한다.

## 4. 데이터베이스

```sql
symbols(code TEXT PK, name TEXT, market TEXT, sector TEXT, updated_at TEXT)
prices(code TEXT, date TEXT, open REAL, high REAL, low REAL, close REAL,
       volume INTEGER, PRIMARY KEY(code, date))          -- 수정주가 기준
indicators_cache(code TEXT, date TEXT, name TEXT, value REAL, PRIMARY KEY(code,date,name))  -- 선택
watchlist(code TEXT PK, memo TEXT, added_at TEXT)
alerts(id INTEGER PK, code TEXT, rule TEXT, active INTEGER, last_fired TEXT)
saved_screens(id INTEGER PK, name TEXT, rule_json TEXT)
backtests(id INTEGER PK, created_at TEXT, params_json TEXT, result_json TEXT)
```

- 가격은 **수정주가**(액면분할·배당 반영)로 저장한다. 안 그러면 지표가 틀어진다.
- 지표는 기본적으로 **조회할 때 계산**(종목 1개 수천 행은 수 ms). 스크리닝처럼 전 종목을 돌 때만 캐시한다.

## 5. 핵심 기능과 구체적 구현

### 5-1. 데이터 수집 (`collector.py`)
1. 종목 목록: `fdr.StockListing('KRX')`(코스피·코스닥), `'NASDAQ'`, `'S&P500'` → `symbols`.
2. 일봉: `fdr.DataReader(code, start)`. 처음엔 최근 5년, 이후는 **DB의 마지막 날짜 다음날부터만** 받는다.
3. 갱신 시각: 평일 장 마감 후(국내 16:00, 미국 다음날 07:00) 스케줄러(APScheduler) 또는 `python manage.py update`.
4. 안전장치: 요청 간 0.3~0.5초 간격, 실패 종목은 목록에 남겨 재시도, 거래정지·상장폐지 종목 표시.
5. 데이터 검증: 고가<저가, 음수, 전일 대비 ±30% 초과(국내 상하한가)는 경고 기록.

### 5-2. 차트 화면 (`/chart/<code>`)
- 위: 캔들 + **이동평균선(5·20·60·120)** + 볼린저밴드 (켜고 끄기 체크박스).
- 중간: 거래량 막대(양봉 빨강·음봉 파랑 — 한국식, 설정으로 전환).
- 아래 패널: RSI(14) / MACD(12,26,9) / 스토캐스틱 중 선택, 최대 2개.
- 기간 버튼: 1M·3M·6M·1Y·3Y·전체, 주봉·월봉 전환(`resample`로 계산).
- 십자선 툴팁(OHLC·등락률·거래량), 로그 스케일 토글.
- **신호 마커**: 골든/데드크로스, RSI 30/70 이탈, MACD 교차를 차트에 ▲▼ 표시.
- 그리기 도구(2단계): 수평선·추세선·피보나치 되돌림 — 좌표를 `drawings` 테이블에 저장.

### 5-3. 지표 (`indicators.py`) — 공식 고정
| 지표 | 정의 |
|---|---|
| SMA(n) | 종가 n일 단순평균 |
| EMA(n) | 지수평균, α = 2/(n+1) |
| RSI(14) | Wilder 평활, 100 − 100/(1+RS) |
| MACD | EMA12 − EMA26, 시그널 = MACD의 EMA9, 히스토그램 = 차이 |
| 볼린저 | SMA20 ± 2×표준편차(모집단) |
| 스토캐스틱 | %K(14,3,3), %D |
| ATR(14) | Wilder 평활 True Range |
| OBV | 상승일 +거래량, 하락일 −거래량 누적 |

→ 테스트는 **알려진 표본값**(교재·TradingView 값)과 소수 3자리까지 대조한다.

### 5-4. 신호·패턴 (`signals.py`, `patterns.py`)
- 골든크로스: 전일 `MA5 ≤ MA20`, 오늘 `MA5 > MA20`. 데드크로스는 반대.
- RSI: 30 아래에서 위로 돌파 = 매수 후보, 70 위에서 아래로 = 과열 해소.
- 거래량 급증: 오늘 거래량 ≥ 20일 평균 × 2.
- 신고가 돌파: 종가가 직전 52주 고가 갱신.
- 볼린저 수축(스퀴즈): 밴드폭이 최근 120일 하위 10%.
- 캔들 패턴: 망치형·장악형·샛별형·도지 (몸통/꼬리 비율 규칙으로 판정).
- 지지/저항: 최근 N일 **피벗 고저점**(좌우 5봉보다 높/낮은 점)을 가격대별로 묶어 빈도 높은 구간 표시.
- 각 신호는 **"왜 떴는지"** 문장(근거 수치)과 함께 보여 준다.

### 5-5. 종목 스크리너 (`/screener`)
- 조건 빌더 UI: `[지표] [연산자] [값/지표]` 행을 AND/OR로 조합.
  예) `종가 > MA20`, `RSI14 < 35`, `거래량 ≥ 거래량MA20 × 2`, `시총 ≥ 1000억`.
- 조건은 JSON(`rule_json`)으로 저장 → 파서가 pandas 연산으로 변환(**eval 사용 금지**, 허용 목록 방식).
- 전 종목(약 2,500) 계산은 마지막 120봉만 읽어 벡터화 → 수 초 목표.
- 결과 표: 종목·현재가·등락률·거래량·충족 조건, 행 클릭 → 차트. 엑셀 내려받기.
- 프리셋: 골든크로스 직후, 눌림목(20일선 지지), 52주 신고가, 거래량 급증 + 양봉.

### 5-6. 백테스트 (`/backtest`)
- 입력: 종목(또는 관심종목 전체), 기간, 전략(골든크로스·RSI 역추세·볼린저 반전·사용자 조건), 초기자금, 수수료·세금(국내 매도 거래세 반영), 슬리피지.
- 규칙: **신호 다음 날 시가 체결**(미래 정보 사용 금지), 손절/익절 %, 1종목 1포지션.
- 결과: 누적수익률, **CAGR, MDD, 승률, 손익비, 거래 횟수**, 보유만 했을 때(Buy&Hold)와 비교 곡선, 거래 내역 표.
- 경고 문구: 과최적화·생존편향(상장폐지 종목 누락) 가능성 안내.

### 5-7. 관심종목·알림 (`/watchlist`)
- 관심종목 + 메모, 현재가·등락·오늘의 신호 한눈에.
- 알림 규칙(예: "삼성전자 RSI<30") → 매일 갱신 후 평가, 발동 시 화면 알림함 + 선택 시 텔레그램 봇/이메일.
- 같은 신호는 하루 1번만 발송(`last_fired`).

## 7. 개발 단계 (순서대로, 각 단계 끝에 동작 확인)

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1 | 프로젝트 뼈대, DB, 종목 목록·일봉 수집 | 삼성전자 5년 일봉이 DB에 들어감 |
| 2 | 지표 계산 + 단위 테스트 | 표본값과 일치, pytest 통과 |
| 3 | 차트 화면(캔들·거래량·MA·볼린저·RSI·MACD) | 브라우저에서 확대·십자선 동작 |
| 4 | 신호·패턴 + 차트 마커 | 골든크로스 지점이 눈으로 맞음 |
| 5 | 관심종목, 일일 자동 갱신 | 다음 날 자동으로 새 봉 추가 |
| 6 | 스크리너 | 전 종목 조건 검색 10초 이내 |
| 7 | 백테스트 | 수동 계산한 작은 사례와 결과 일치 |
| 8 | 알림(텔레그램), 그리기 도구, 분봉(선택) | — |

MVP = 1~4단계. 여기까지 되면 이미 "쓸 수 있는" 프로그램이다.

## 8. 품질·위험 관리

- **정확성**: 수정주가 사용, 휴장일·결측 처리, 지표는 외부 값과 대조.
- **성능**: 차트는 최근 N봉만 전송(기본 500), 나머지는 스크롤 시 추가 요청. 전 종목 계산은 numpy 벡터화.
- **데이터 출처 약관**: 무료 라이브러리는 비공식 크롤링 기반이라 구조가 바뀌면 깨질 수 있음 → 수집 모듈을 `collector.py` 한 곳에 격리해 교체 가능하게 한다. 재배포 시 데이터 재판매·공개 금지.
- **보안**: 비밀값(텔레그램 토큰, 증권사 키)은 환경변수, DB·저장소에 넣지 않는다. CSP 유지(인라인 스크립트 금지).
- **면책**: 모든 화면 하단 "투자 참고용 도구이며 수익을 보장하지 않습니다."
