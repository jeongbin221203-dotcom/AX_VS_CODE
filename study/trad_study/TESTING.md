## 실제 브라우저 확인 (2026-10-10, 헤드리스 Chrome)

웹 주소(`http://127.0.0.1:5964`)로 연 경우 **34/34**, `index.html`을 파일로 직접 연 경우(`file://`) **34/34**, 콘솔 오류 0건. 새 브라우저 프로필에서 다음을 직접 눌러 확인했습니다.

- 첫 화면 → 학습 연습 시작 → 원문 이미지(상대 경로 `img/*.webp`)가 모두 뜸 → 답 선택 → 새로 고침 후에도 유지
- 처음에는 **정답 파일(`answers.js`)을 불러오지 않음** → 제출하는 순간 불러와 채점, 결과 화면에 공식 정답과 상대 경로 정답표 PDF 링크
- 글꼴이 부분집합 woff2로 로드됨(318KB), IndexedDB 동작
- AI(가짜 응답으로 가로채 요청만 검사): 연결 → 요청 주소·`Bearer` 헤더 → 학습 연습에서 질문하면 정답이 빠진 힌트 요청 → 결과 화면에서 해설이 자동 생성되고 요청에 정답 포함 → 새로 고침해도 해설(IndexedDB)과 키(탭)가 유지 → 키는 `sessionStorage`에만 있고 `localStorage`·백업 파일에는 없음 → 연결 해제 시 키 삭제
- 웹 주소 방식은 문제 그림 1장이 AI 요청에 붙고, `file://` 방식은 글자만 전송
- 메모 자동 저장 → 오답노트 목록·미리보기
- 백업 파일 생성 → 저장소 삭제 → 빈 화면 → 복원(시험 1회·메모 1개·AI 해설 1개) → 잘못된 파일은 창 안에 오류 표시
