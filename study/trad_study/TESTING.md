# 검증 결과

## 데이터

- 제59~65회 문제·정답 PDF 14개 사용
- 7회 × 4과목 × 30문항 = 840문항
- 정답표의 과목별 열, 문제 번호와 정답 기호의 행 위치를 대조
- 모든 문항에서 보기 ①~④ 존재 확인
- 공유 지문 42묶음을 해당 문항에 연결
- PDF 원문 영역의 대표 사례 6개를 실제 PNG로 렌더링해 내용과 보기 확인
- 원본별 페이지 수와 SHA-256은 `data/validation.json`에 기록

## 서버 자동 테스트

`python -m pytest tests -q` 결과: **34 passed**

- 28개 회차·과목 조합에서 모든 답을 공식 정답으로 제출하면 100점
- 제출 전 응답에 정답 값 미포함
- 답안·다시 보기 표시 저장, 시험 재개, 제출의 중복 실행 처리
- 제출 후 답안 수정 거부, 시간 종료 시 자동 채점
- 미응답을 포함한 오답 집계, 복습 완료 필터와 오답 재시험
- 프로세스를 다시 만들어도 메모 유지, 백업 파일 복원 검사
- CSRF·요청 출처·허용 호스트 검사
- 원본 문제와 공유 지문 이미지 응답 검사
- 세션별 API 키 분리, 쿠키·백업에 키 미포함
- AI 해설 생성 결과 저장, 재열람 시 API 재호출 없음

AI 요청은 가짜 응답으로 대체해 검증했습니다. 실제 사용자 키를 사용한 유료 API 호출은 수행하지 않았습니다.

## 화면 스크립트 동작

실제 Flask 서버와 JSDOM을 연결해 다음 흐름을 통과했습니다.

홈 → 59회 선택 → 무역규범 시험 시작 → 답안 선택 → 나중에 보기 표시 → 다음 문제 → 답안 선택 → 홈 → 이어 풀기 → 제출 → 점수 확인 → 메모 자동 저장 → 복습 완료 → 오답 필터 → 메모 재확인 → AI 키 입력 화면 → 핵심 개념 → 학습 기록

JavaScript 런타임 오류가 없었으며, 메모에 입력한 HTML이 실행되지 않음을 확인했습니다.

현재 검증 환경에서 실제 브라우저 프로세스를 실행하지 못했습니다. 따라서 데스크톱·모바일의 최종 픽셀 배치, 실기 키보드 조작 및 실제 모델의 해설 정확성은 미검증입니다. 반응형 CSS, 로컬 한글 글꼴과 접근성 레이블은 포함했습니다.
