**서버 (`tests/test_app.py`)**

- 문제 목록 840개에 정답 값이 없고, 28개 회차·과목 묶음이 각각 30문항
- `/api/answers`가 돌려주는 공식 정답 840개가 정답 파일과 일치, 잘못된 요청(빈 목록·121개·범위 밖 번호) 거부
- 서버에 학습 기록 API가 없음(예전 `/api/dashboard`·`/api/attempts` 등은 404)
- CSRF·요청 출처·허용 호스트 검사, HTTPS 프록시(Render) 뒤에서 요청 통과
- 원본 문제와 공유 지문 이미지 응답 검사
- API 키가 응답·쿠키에 안 남음, 세션별 키 분리, AI 해설은 매번 새로 만들어 돌려주고(저장은 브라우저), 제출 전 학습 연습은 정답을 숨김
- 예전 `study-backup.sqlite3`를 브라우저 기록으로 변환, 잘못된 파일(다른 파일·표 없음·맞지 않는 문항·CSRF·50MB 초과) 거부

**브라우저 기록 저장소 (`tests/store.test.js`, Node 16개 시험, pytest가 실행)** — 실제 문항 840개와 공식 정답 사용

- 28개 회차·과목 시험을 모두 공식 정답으로 풀면 100점, 제출 전에는 정답이 보이지 않음
- 120문항 전 과목 시험, 틀린 답과 미응답이 오답노트에 쌓임, 가장 최근 틀린 답 기록
- 이어 풀기(선택·나중에 보기·마지막 위치), 제한 시간 지나면 자동 제출, 서버에 못 닿으면 보류했다가 채점
- 잘못된 입력 거부, 제출 두 번 눌러도 한 번만 반영, 제출 후 수정 금지
- 메모·복습 완료·오답 다시 풀기, 다시 틀리면 복습 목록으로 복귀(메모 유지)
- AI 해설은 처음 한 번만 만들고 이후 저장본 사용, 제출 전 실전 연습 AI 금지·학습 연습 정답 숨김
- 저장 장치를 다시 열어도(서버를 다시 켜도) 기록 유지, 동시에 30번 저장해도 하나도 잃지 않음
- 백업 내보내기 → 새 저장소로 복원, 복원은 기존 기록을 교체, 고친 흔적·잘못된 번호·범위 밖 값이 든 백업 13종 거부
- 예전 서버 백업을 바꾼 기록 복원

AI 요청은 가짜 응답으로 대체해 검증했습니다. 실제 사용자 키를 사용한 유료 API 호출은 수행하지 않았습니다.

## 실제 브라우저 확인 (2026-10-10, 헤드리스 Chrome, 32/32)

새 브라우저 프로필에서 다음을 직접 눌러 확인했습니다.

- 첫 화면은 기록 없음 → 59~65회 중 시험 시작 → 원문 이미지가 모두 뜸 → 답 선택(저장 표시)
- **서버를 완전히 껐다 다시 켠 뒤** 새로 고침해도 "이어서 풀 준비" 카드가 뜨고, 고른 답과 보던 문제 위치가 그대로
- 제출 → 공식 정답으로 채점된 결과 화면, 정답 표시
- 메모 입력 → 자동 저장 → 새로 고침 후에도 유지, 오답노트 목록·미리보기·사이드바 숫자
- 백업 파일 생성(`study-backup-날짜.json`) → 브라우저 저장소를 지움 → 홈이 비어 있음 → 복원 → 시험·메모 되살아남
- 예전 `study-backup.sqlite3` 복원 → 시험 2회·메모·해설 복원, 잘못된 파일은 창 안에 오류 표시하고 기록은 그대로
- 서버에는 학습 기록 주소가 없음, 콘솔 오류 0건

미검증: 휴대폰·다른 브라우저(Safari/Firefox)의 IndexedDB 동작, 실제 OpenAI 키로 해설을 만드는 흐름, 데스크톱·모바일의 세부 픽셀 배치.
