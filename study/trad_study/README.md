# 무역연습실 · 국제무역사 1급 (HTML 버전)

제59~65회 기출 7회분(840문항)과 공식 정답표를 담은 **서버 없는 학습 웹**입니다. 파이썬·Flask 없이 HTML·JavaScript만으로 동작해서, 폴더를 어떤 정적 호스팅에 올려도 되고 `index.html`을 더블클릭해도 열립니다.

> Flask 서버로 돌리는 같은 앱은 옆 폴더 [`../trad`](../trad)에 있습니다. 이 폴더는 그 앱을 서버 없는 구조로 다시 만든 것입니다.

**내 학습 기록(풀이·메모·AI 해설)은 쓰는 브라우저에만 저장됩니다.** 서버가 없으니 잠들거나 꺼질 일이 없고, 기록이 다른 사람과 섞이지도 않습니다. 대신 기기를 바꾸거나 브라우저 데이터를 지울 때는 `학습 기록 백업`·`복원`을 쓰세요.

## 바로 시작하기

**방법 1 — 더블클릭:** `index.html`을 브라우저로 엽니다. (Chrome에서 확인. 이 방식에서는 AI에 문제 *그림*을 붙여 보내지 못하고 글자만 보냅니다. 아래 "AI" 참고)

**방법 2 — 로컬 서버(권장):** 파이썬이 있으면 `start.bat`(Windows) 또는 `sh start.sh`를 실행하고 http://127.0.0.1:5091 을 엽니다. 파일을 보여 주기만 하는 서버(`python -m http.server`)입니다. 5091번이 사용 중이면 `python -m http.server 5092` 처럼 다른 번호로 직접 실행하세요. (Flask 버전은 5090번을 씁니다.)

**방법 3 — 인터넷에 올리기:** 이 폴더 전체를 GitHub Pages·Render Static Site·Netlify 같은 정적 호스팅에 올리면 됩니다. 별도 빌드가 필요 없고(Publish Directory = 이 폴더), 서버 비용·잠들기·재배포로 기록이 사라지는 일이 없습니다.

## 구현된 기능

| 기능 | 사용 방법 |
|---|---|
| 회차·과목별 시험 | 59~65회에서 회차를 고르고 4과목 중 하나를 선택해 30문항 풀이 |
| 전 과목 시험 | `전 과목 풀기`로 회차당 120문항 풀이 |
| 실전·학습 모드 | 실전은 제출 후 AI 사용, 학습은 풀이 중 AI 힌트 사용 |
| 연습 타이머 | 제한 없음 또는 30·40·60·120분, 시간 종료 시 저장된 답안으로 제출 |
| 답안 저장·이어서 풀기 | 답을 선택할 때마다 이 브라우저에 저장, 홈 또는 학습 기록에서 이어 풀기 |
| 문항 탐색 | 번호판, 이전·다음, 키보드 방향키, 1~4번 답 선택, 나중에 볼 문제 표시 |
| 채점·결과 | 공식 정답표 기준 채점, 미응답은 오답 처리, 문항별 공식 정답 표시 |
| 과목별 오답노트 | 과목·복습 상태 필터, 제목·메모 검색, 오답 다시 풀기 |
| 개인 메모 | 문제별 메모 자동 저장, 복습 완료 표시, 재풀이 후에도 메모 유지 |
| AI 챗봇·해설 | 현재 문항의 원문·공통 지문을 참고하는 질문 답변, 해설 생성 후 이 브라우저에 저장 |
| 학습 기록 백업·복원 | 왼쪽 메뉴에서 JSON 파일로 내려받고 다시 올리기 |
| 핵심 개념 | 과목별 간단한 학습 안내와 기본 용어 |

시험 화면은 시험지 PDF의 **원본 문항 영역을 미리 만들어 둔 이미지(`img/`)로 표시**합니다. 밑줄, 표, 영어 서신과 보기의 모양을 보존합니다. `문제 텍스트로 보기`와 원본 PDF 링크도 있습니다.

### 타이머와 오답 처리

- 제한 시간은 개인 연습용 설정입니다. 공식 시험 시간이나 공식 CBT 화면을 그대로 복제한 서비스는 아닙니다.
- 제한 시간을 정한 시험은 창을 닫아도 시간이 흐릅니다. 다시 열면 시간이 지난 시험은 저장된 답안으로 채점됩니다.
- 오답노트에는 **한 번이라도 틀린 문항**이 남습니다. 미응답 문항도 포함됩니다.
- `복습 완료`를 체크하면 복습할 목록에서 빠지고, 나중에 같은 문항을 다시 틀리면 복습할 목록으로 돌아옵니다. 메모는 유지됩니다.
- 오답 재시험은 현재 선택한 과목의 미완료 오답을 최대 120문항까지 포함합니다.
- 점수는 정답 수 / 문항 수 × 100입니다. 공식 합격·과락 판정은 별도로 제공하지 않습니다.

## 학습 기록과 백업

기록은 브라우저의 IndexedDB(`trade-study`)에 저장됩니다. 주소(출처)마다 따로 저장되므로 `index.html`을 직접 연 것, `127.0.0.1:5091`, 인터넷 주소의 기록은 서로 별개입니다.

1. 왼쪽의 `학습 기록 백업` → `study-backup-날짜.json` 다운로드
2. `학습 기록 복원` → 파일 선택 → `복원하기`. 이 브라우저의 지금 기록은 **백업 내용으로 모두 바뀝니다**(합치기 아님).

손상되었거나 이 앱의 백업이 아닌 파일, 이 앱의 문제와 맞지 않는 값이 든 파일은 거부하고 기존 기록을 그대로 둡니다(50MB까지). 백업에는 풀이·메모·AI 해설이 들어가며 API 키는 들어가지 않습니다.

**기록이 사라지는 경우:** 브라우저의 "사이트 데이터 삭제", 시크릿(비공개) 창, 다른 브라우저·기기. 저장 공간이 부족할 때 브라우저가 지울 수도 있어 앱이 영구 저장을 요청하지만 보장되지는 않습니다. 가끔 백업해 두세요. Flask 버전([`../trad`](../trad))이 만든 `study-backup-날짜.json`은 같은 형식이라 이 버전에서도 복원되고 반대도 됩니다. 아주 예전 서버 방식의 `study-backup.sqlite3`는 Flask 버전의 복원 화면에서 올린 뒤 다시 백업(JSON)하면 됩니다.

## AI 키를 웹에서 입력하기

1. 오른쪽 위의 **AI 연결하기** → 본인의 OpenAI API 키 입력 → 모델 입력(기본 `gpt-4.1-mini`, 이미지 입력을 지원하는 모델) → `연결 확인·사용`.
2. 서버가 없으므로 **이 브라우저가 OpenAI에 직접 요청**합니다. 키는 이 탭의 `sessionStorage`에만 두며 탭을 닫으면 사라집니다(8시간 뒤 만료, `연결 해제`로 즉시 삭제). 학습 기록·백업 파일·localStorage에는 넣지 않고, 인터넷 서버에 보내지 않습니다.
3. 전송 내용: 선택한 문제·공통 지문의 글자와 그림, 질문, 최근 대화. 연결 확인·질문·해설 생성에는 API 사용 비용이 발생할 수 있습니다.
4. AI 설명은 **공식 해설이 아닌 AI 초안**입니다. 해설은 처음 열 때 한 번 만들어 이 브라우저에 저장하고 다음에는 API를 부르지 않습니다.

주의할 점:

- 키가 틀렸을 때 OpenAI의 오류 응답은 브라우저가 상태 코드를 읽을 수 없어 "연결하지 못했습니다. 인터넷 연결과 API 키가 맞는지 확인해 주세요."로 보입니다.
- `index.html`을 더블클릭해서 연 경우 브라우저가 로컬 이미지 읽기를 막아 문제 그림은 못 붙이고 글자만 보냅니다. 그림 속 표·서신이 중요한 문제는 로컬 서버(방법 2)나 인터넷 주소로 여세요.
- 실전 연습 중 "제출 전 AI 금지"와 학습 연습의 "정답 숨김"은 화면이 지키는 규칙입니다. 서버가 없어서 개발자 도구를 쓰면 우회할 수 있습니다(스스로 공부하는 용도). 공식 정답 파일(`data/answers.js`)은 채점할 때만 불러옵니다.
- 지원 API는 **OpenAI Responses API**뿐입니다. 챗봇 대화는 문항을 바꾸면 초기화되고 해설·메모는 저장됩니다.

총 **840문항**, 과목별 **210문항**, 공통 지문 **42개 묶음**입니다. 사용자가 제공한 최종 PDF를 기준으로 하며, 앞서 제출된 HWP 변환 실패 파일이나 중복 문제지는 사용하지 않습니다.

문항을 PDF에서 읽을 때 60회 무역규범 13번의 마침표 생략, 62회 무역계약 28번의 다른 들여쓰기, 다음 페이지까지 이어지는 공통 지문을 처리했습니다(변환 규칙은 Flask 버전의 `scripts/build_catalog.py`). 원본별 쪽수와 문제 PDF의 SHA-256, 회차별 공통 지문 묶음 수는 `data/validation.json`에 있습니다. 이 폴더의 데이터가 Flask 버전과 같은지는 `scripts/verify_against_flask.py`로 대조합니다(아래 "검증").

```text
trad_study/
  index.html                화면(이 파일 하나가 시작점)
  static/
    app.js                  화면 동작
    store.js                학습 기록 저장소: 시험·채점·오답노트·메모·백업을 브라우저에서 처리(IndexedDB)
    ai.js                   OpenAI 직접 호출·키 보관
    style.css, favicon.svg
    fonts/                  쓰는 글자만 남긴 글꼴(NotoSansKR 부분집합 woff2, OFL 라이선스)
  data/
    catalog.js              문항 840개(정답 없음, 이미지 주소 포함)
    answers.js              공식 정답 840개 — 채점할 때만 불러옴
    sources/                원본 시험지·정답표 PDF 14개
    validation.json         변환 검사 결과와 문제 PDF 해시
  img/                      문항·공통 지문 이미지 883개(WebP, 같은 그림은 한 파일)
  scripts/build_data.py     ../trad 의 문항 DB·PDF 에서 data/·img/·글꼴을 다시 만드는 도구
  scripts/verify_against_flask.py   만든 데이터가 Flask 버전과 같은지 대조(글·정답·이미지 픽셀·PDF 해시)
  tests/                    Node 테스트 (store·ai·data)
  .vscode/launch.json       VS Code F5 로 Chrome 에서 index.html 열기
  start.bat / start.sh      로컬 서버(5091번)
```

전체 약 30MB입니다(이미지 24MB, PDF 4MB). `data/`·`img/`·글꼴은 결과물을 저장소에 함께 올려 두었으므로 PDF나 문항이 바뀔 때만 다시 만들면 됩니다.

```powershell
pip install -r requirements-build.txt
python scripts/build_data.py              # 문항·이미지·정답·글꼴 전체 (약 1~2분)
python scripts/build_data.py --font-only  # 화면 글자가 바뀌어 글꼴만 다시 만들 때
```

`scripts/build_data.py`는 `../trad`(Flask 버전 폴더)의 `catalog.sqlite3`와 글꼴 원본을 읽습니다. 그 문항 DB를 PDF에서 새로 만드는 `build_catalog.py`도 Flask 버전 쪽(`../trad/scripts/`)에만 있으므로, PDF·문항을 바꿀 때는 먼저 거기서 DB를 만든 뒤 이 폴더의 도구를 실행하세요. 이 폴더만 따로 올려 쓰는 데는 필요 없습니다(결과 파일이 이미 들어 있음).

## 사용 범위

로그인 없는 **한 사람의 학습**을 전제로 합니다. 기록은 각 브라우저가 따로 가지며 기기 간 자동 동기화는 없습니다(백업·복원으로 옮김). 이 폴더를 인터넷에 올리면 누구나 문제·PDF를 볼 수 있습니다.

기출문제와 정답표의 출처는 사용자가 제공한 국제무역사 1급 시험 PDF이며, 그 권리는 원 저작권자에게 있습니다. Noto Sans KR 글꼴의 부분집합을 포함하며 라이선스는 `static/fonts/OFL.txt`에 있습니다.
