# TS 단어 (TS_word)

TS 영어 시험 앱의 **단어 공부 기능만** 뽑아 서버 없이 HTML·JS로 돌아가게 만든 것입니다.
토익 단어 1,800개 + 토플 학술 어휘 800개.

## 쓰는 법
- `index.html` 을 더블클릭하면 바로 열립니다 (서버·설치 필요 없음).
- 휴대폰에서 쓰려면 폴더를 정적 호스팅(GitHub Pages 등)에 올리거나, PC에서 `python -m http.server 8000` 후 같은 와이파이에서 접속합니다.
  (`file://` 로 열면 휴대폰 브라우저가 막는 경우가 많습니다.)

## 화면
| 파일 | 내용 |
|---|---|
| `index.html` | 홈: 오늘 복습·새 단어 개수, 등급별 진행 |
| `study.html` | 카드 학습: 뜻 보기 → 다시/어려움/보통/쉬움 (단축키 Space, 1~4, S) |
| `quiz.html` | 뜻 고르기 시험: 전체·자주 잊는·최근 틀린·별표·학습 중, 틀린 단어만 다시 |
| `list.html` | 단어장: 등급·필수/도전·상태·검색, 발음·별표 |
| `listen.html` | 듣기 모드: 영어 N번 → 한국어 뜻 → 예문 (운전·산책용) |
| `settings.html` | 하루 새 단어 수, 음성, **백업·복원·초기화** |

위쪽 `토익 / 토플` 로 단어 세트를 바꿉니다. 세트마다 학습 기록은 따로입니다.

## 복습 일정
TS 앱(`core/srs.py`)과 같은 규칙입니다. 모름 → 내일 다시, 알면 1일 → 4일 → 이전 간격 × 계수, 간격 21일 이상 = 암기 완료.
파이썬과 자바스크립트의 반올림이 달라(6.5 → 6 / 7) 일정이 어긋나므로 파이썬 방식으로 맞춰 두었고,
`tests/store.test.js` 가 384개 경우를 파이썬 결과와 대조합니다.

## 기록은 어디에 저장되나
이 브라우저의 localStorage(`ward:v1`)에만 저장됩니다. **서버가 없어서 기기끼리 합쳐지지 않습니다.**
브라우저 데이터를 지우거나 기기를 바꾸기 전에 설정 → 백업 파일을 내려받으세요. 같은 화면에서 불러올 수 있습니다.

## 단어를 바꾸려면
단어 원본은 TS 앱의 `content/toeic/vocab*.json`, `content/toefl/vocab*.json` 입니다. 고친 뒤:

    python tools/build_data.py            # ../TS 를 읽어 data/toeic.js, data/toefl.js 를 다시 만듭니다

`data/*.js` 는 직접 고치지 마세요(자동 생성). `file://` 에서도 열리도록 JSON 대신 `<script>` 로 읽는 `.js` 로 만듭니다.

## 검사
    node tests/store.test.js              # 복습 계산·저장·백업 (노드만 있으면 됩니다)

## TS 앱과 다른 점
- 1시간짜리 MP3 만들기는 없습니다(서버가 필요). 듣기 모드는 브라우저 음성으로 읽습니다.
- 학습 기록이 TS 앱과 따로입니다 (TS 앱의 기록을 가져오는 기능은 없음).
- 점수·등급에 맞춘 "내 등급부터 새 단어"는 없고 1등급부터 나옵니다. 등급을 눌러 원하는 곳부터 하세요.
