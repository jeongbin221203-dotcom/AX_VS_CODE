# TS 단어 (TS_word)

TS 영어 시험 앱의 **단어 공부 기능 전부**를 서버 없이 HTML·JS로 돌아가게 만든 것입니다.
토익 단어 1,800개 + 토플 학술 어휘 800개.

## 쓰는 법
- `index.html` 을 더블클릭하면 바로 열립니다 (서버·설치 필요 없음).
- **휴대폰에서 쓰려면** 폴더를 정적 호스팅(GitHub Pages 등)에 올리거나, PC에서 `python -m http.server 8000` 후 같은 와이파이로 접속합니다.
  서버로 열면 **홈 화면에 설치**할 수 있고, 한 번 열어 두면 **인터넷이 없어도** 공부됩니다(서비스 워커).
  `file://` 로는 휴대폰 브라우저가 막는 경우가 많습니다.

## 화면
| 파일 | 내용 |
|---|---|
| `index.html` | 홈: 오늘 복습·새 단어 개수, 내 등급 단어 진행, 등급별 진행 |
| `study.html` | 카드 학습: 뜻 보기 → 다시/어려움/보통/쉬움 (단축키 Space, 1~4, S) |
| `quiz.html` | 뜻 고르기 시험: 전체·자주 잊는·최근 틀린·별표·학습 중, 틀린 단어만 다시 |
| `list.html` | 단어장: 등급·필수/도전·상태·검색, 발음·별표 |
| `listen.html` | 듣기 모드: 영어 N번 → 한국어 뜻 → 예문·철자, 정지·이전·다음, 화면 켜짐 유지 |
| `settings.html` | 하루 새 단어 수, **내 등급(토익 점수로 정하기)**, 음성, 백업·불러오기(합치기/바꾸기)·초기화 |

위쪽 `토익 / 토플` 로 단어 세트를 바꿉니다. 세트마다 학습 기록은 따로입니다.

## TS 앱에서 옮긴 것
| TS 앱 기능 | 여기서는 |
|---|---|
| 카드 학습·간격 반복 | 그대로 (`js/store.js`, 같은 규칙) |
| 뜻 고르기 시험·틀린 단어 다시 | 그대로 |
| 단어장(검색·필터·별표) | 그대로 |
| 듣기 모드(운전 모드) | 그대로 (철자 읽기 포함) |
| 내 등급부터 새 단어 | **설정 → 내 등급** (점수를 넣으면 자동) |
| 1시간 MP3 만들기 | `tools/make_audio.py` (컴퓨터에서 한 줄 실행 — 아래) |
| 학습 기록 | `tools/import_ts_db.py` 로 TS 앱 기록을 가져옴 (아래) |
| 설치·오프라인 | 매니페스트 + 서비스 워커 |
| 기기 간 동기화 | **없음** — 서버가 없어서. 백업 파일로 옮깁니다 |

## 복습 일정
TS 앱(`core/srs.py`)과 같은 규칙입니다. 모름 → 내일 다시, 알면 1일 → 4일 → 이전 간격 × 계수, 간격 21일 이상 = 암기 완료.
파이썬과 자바스크립트의 반올림이 달라(6.5 → 6 / 7) 일정이 어긋나므로 파이썬 방식으로 맞춰 두었고,
`tests/store.test.js` 가 384개 경우를 파이썬 결과와 대조합니다.

## 기록은 어디에 저장되나
이 브라우저의 localStorage(`ward:v1`)에만 저장됩니다. **기기끼리 합쳐지지 않으니**
브라우저 데이터를 지우거나 기기를 바꾸기 전에 설정 → 백업 파일을 내려받으세요.
불러올 때 **합치기**(지금 기록 + 파일, 카드는 나중에 복습한 쪽, 별표는 어느 한쪽이라도)와 **바꾸기**(통째로 교체)를 고를 수 있습니다.

## TS 앱 기록 가져오기
    python tools/import_ts_db.py                 # ../TS/data/ts.db → ts-word-backup.json (원본 DB 는 읽기만 함)

만든 파일을 설정 → 백업 불러오기(합치기)로 불러옵니다. 복습 카드·복습 기록·시험 기록·하루 새 단어 수·음성 설정이 옮겨집니다.

## 긴 MP3 만들기 (화면을 끄고 듣기)
브라우저만으로는 음성 파일을 만들 수 없어서 컴퓨터에서 실행합니다.

    pip install edge-tts lameenc
    python tools/make_audio.py --set toeic --level 1 --tier core --minutes 60 --repeats 3
    python tools/make_audio.py --set toeic --which weak --backup ts-word-backup.json   # 자주 잊는 단어만

`audio/` 폴더에 `토익단어_Orange_필수_60분_01.mp3` 처럼 만들어집니다(이 폴더는 git 에 올리지 않음).
**듣기 화면(listen.html) 아래에 지금 고른 조건 그대로의 명령이 만들어져** 복사만 하면 됩니다.
음성은 Microsoft 온라인 음성(edge-tts)이라 인터넷이 필요하고, 처음엔 몇 분 걸립니다(만든 조각은 `audio/clips/` 에 남아 다음엔 빠름).

## 단어를 바꾸려면
단어 원본은 TS 앱의 `content/toeic/vocab*.json`, `content/toefl/vocab*.json` 입니다. 고친 뒤:

    python tools/build_data.py            # ../TS 를 읽어 data/toeic.js, data/toefl.js 를 다시 만듭니다

`data/*.js` 는 직접 고치지 마세요(자동 생성). `file://` 에서도 열리도록 JSON 대신 `<script>` 로 읽는 `.js` 로 만듭니다.
단어를 고치거나 파일을 더하면 `sw.js` 의 `CACHE` 이름(`ts-word-v1`)을 올려야 오프라인 복사본이 새로 만들어집니다.
