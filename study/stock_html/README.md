# 실시간 신호 차트 (토스증권 Open API, 개인 분석용)

차트를 분석해 매수·매도 시점을 표시합니다. 주문 기능은 없습니다.

## 실행
1. `.env` 에 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET` (토스 WTS > Open API). 이 PC의 공인 IP가 허용 목록에 있어야 합니다.
2. `start.bat` (또는 `npm install` → `node server.mjs`) → http://127.0.0.1:5100
3. 테스트: `npm test`

## 구조
- `server.mjs` — 로컬 중계 서버(127.0.0.1 만 접속). 토큰 발급·갱신, REST 중계(`/api/candles`, `/api/prices`), 토스 WebSocket 을 SSE(`/stream`)로 중계. 브라우저는 토스에 직접 붙지 않습니다(WebSocket 헤더 인증 불가, 토큰 1개만 유효).
- `public/js/indicators.js` · `signals.js` — 지표·신호·봉 묶기·백테스트(순수 함수, Node 테스트 대상)
- `public/js/app.js` — 차트(Lightweight Charts 4.2.0, CDN)·화면

## 종목 목록
- 상단 `국내` / `해외` 탭으로 시장을 고르고, 입력칸(또는 `전체 종목`)에서 종목명·코드로 검색합니다. 거래소(코스피·코스닥 / NYSE·나스닥·AMEX)와 유형(주식·ETF·ETN·리츠 등)으로 거를 수 있습니다.
- 전체 종목은 토스 `GET /api/v1/stocks/all` 로 받아 `data/universe-*.json` 에 하루 1회 캐시합니다(2026-10-17 기준 국내 4,306개·해외 11,149개). 한도가 초당 1회라 하루 첫 조회는 시장 7개를 순차로 받느라 10초쯤 걸립니다.

## 기간·과거 데이터
- 화면 위의 기간 버튼(분봉: 1일·3일·1주·2주·1개월·3개월·전체 / 일봉: 3개월~10년·전체)으로 **보이는 구간**만 고릅니다. 데이터는 그보다 더 받아 두어서 왼쪽으로 끌면 이어서 보이고, 왼쪽 끝에 닿으면 과거를 더 불러옵니다. 오른쪽 백테스트·신호 목록은 지금 화면에 보이는 기간 기준입니다.
- 일봉은 토스가 주는 전체(삼성전자 1975년~ 13,755개, 애플 1990년~ 9,266개)를 자동으로 받습니다. 분봉은 최근 3,000봉으로 먼저 그리고, 선택한 기간이 채워질 때까지 5,000봉씩 백그라운드로 이어받습니다(상한 20만봉, 5,000봉에 2~3초). 분봉은 약 9개월(국내)·4.5개월(해외)치까지 있습니다.
- 이동평균선은 MA5·10·20·60·120·200을 버튼으로 켜고 끕니다(기본 5·20·60·120). 신호 계산에는 MA5/MA20만 쓰고 나머지는 참고용 표시입니다.

## 점수형 신호 (대형주용)
지표별 이벤트에 점수를 주고 **최근 5봉 합계가 3점 이상**이 되는 순간 신호. 매수 점수가 더 높으면 매수, 매도 점수가 더 높으면 매도. 신호는 매수 → 매도 순서로만 남김.
- 골든/데드크로스(MA5/MA20) +2, RSI 30 위로 탈출/70 아래로 이탈 +2, MACD 히스토그램 양전환/음전환 +2, 볼린저 하단 반등/상단 하락(캔들 방향 확인) +1, 거래량 20봉 평균의 1.5배↑(위 이벤트와 같은 봉일 때) +1.
- 체결은 신호 다음 봉 시가로 가정(백테스트와 동일). 오른쪽 '현재 판단'에 매수·매도 점수표(이벤트별 점수)가 나옵니다.
- 검증(시총 상위 100종목, 최근 5년 일봉, 수수료 한쪽 0.1%): 수익이 난 종목 75%(전반 2.5년 70%·후반 72%), 평균 +84%·중앙값 +40%, 매매 승률 47%, 단순 보유(평균 +332%)보다는 낮음. 보유보다 나은 종목은 23개. 매매 승률 70%는 어떤 방식·구간에서도 나오지 않음.

## 규칙형 신호 (기본 방식 아님, 직접 선택 시)
- **매수 — 3가지를 모두 충족**: ① 추세 상승(종가 ≥ MA60 이고 MA20 ≥ MA60) ② 모멘텀 전환(최근 3봉 안에 MACD 히스토그램 음→양) ③ RSI 상승 구간(40 ≤ RSI14 < 80)
- **매도 — 보유 중일 때 하나라도**: ① 손절(종가 < 매수 신호 종가 − 2×ATR14) ② 추세 이탈(종가 < MA20 이고 MACD 히스토그램 < 0) ③ RSI 지지 이탈(RSI14가 40 위에서 아래로)
- 체결은 신호가 난 다음 봉 시가로 가정(백테스트와 동일). 마지막(진행 중) 봉의 신호는 봉이 닫히기 전 바뀔 수 있음. 오른쪽 '현재 판단'에 각 조건의 충족 여부(✓/✗)와 수치가 나옵니다.
- 숫자는 `public/js/signals.js` 의 `RULES` 에서 바꿉니다.

## 지표 설정 (표준 기본값)
- 볼린저(20, 2σ): 20봉 단순이동평균 ± 2×표준편차(모집단). 밴드 터치는 신호로 쓰지 않고 %B·밴드폭(최근 126봉 중 하위 10%면 '수축')으로 상태만 표시.
- RSI(14, Wilder 평활): 상승 추세 40~80, 하락 추세 20~60, 그 외 30~70 구간으로 읽음(Cardwell).
- MACD(12, 26, 9): MACD선과 시그널선, 히스토그램. 0선 위/아래와 시그널선 위/아래를 표시.
- 세 설정은 널리 쓰이는 표준 기본값입니다. 기관 전용의 별도 설정값은 확인하지 못했습니다(자료가 증권사·차트 서비스 교육 페이지 위주).
