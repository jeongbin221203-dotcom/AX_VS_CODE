메신저별 준비 방법
  • 잔디: 토픽 → 연동하기 → Webhook 수신(Incoming Webhook) 추가 → 만들어진 URL 을 붙여 넣습니다.
  • 네이버웍스: Developer Console 에서 앱(Client ID·Secret)과 Service Account·Private Key 를 만들고, 봇을 등록해 Bot ID 를 받습니다(권한 bot). 채널방에 보내려면 봇을 방에 초대한 뒤 채널 ID 를, 개인 메시지는 사용자 이메일(웍스 ID)을 씁니다.
  • 카카오워크: 관리자 → 봇 → 봇 만들기 → App Key. 알림 받는 사람의 카카오워크 이메일로 보냅니다.
  • Slack: Incoming Webhooks 앱 URL. Teams: 채널 → 워크플로 → '웹후크 요청이 수신되면 채널에 게시' URL.
  • 토큰·키는 암호화해서 저장하고 화면에는 끝 4자리만 보입니다. 실제 각 서비스 서버로의 발송은 공개 API 형식대로 만들었고 가짜 서버로 검증했습니다.
