# 자재관리 보안 점검

## 이 문서의 범위

**모의해킹(외부 전문가가 공격자처럼 시험)은 하지 않았다.** 여기 적은 것은 개발자가 스스로 한 점검이다:
자동 보안 테스트, 정적 분석(bandit), 의존성 취약점 검사(pip-audit), 그리고 적용한 통제 목록.
운영 전에는 아래 '외부 점검 권고 범위'로 전문 업체 점검을 받는 것을 권한다.

## 자동 점검 (CI 에서 매번 — `.github/workflows/material-ci.yml`)

| 점검 | 방법 | 결과 (2026-10-03) |
|---|---|---|
| 로그인 없이 열리는 화면 | 모든 화면 주소를 로그인 없이 열어 봄 (`tests/test_security.py`) | 정해 둔 것(로그인·최초 설정·/health·/metrics·정적 파일)만 열림 |
| CSRF | 상태를 바꾸는 모든 요청을 표 없이 보냄 | 모두 400 |
| 권한 | 조회 역할로 모든 쓰기 요청 | 모두 거부(403/400) |
| 창고 범위(IDOR) | 범위 밖 작업지시 열람·투입, 범위 밖 창고 여러 줄 등록, 목록 노출 | 모두 차단 |
| XSS | 거래처 이름에 스크립트 → 목록·상세 | 글자로만 보임 |
| SQL 주입 | 검색어에 `' OR 1=1 --` 등 | 오류 없이 글자로 검색 |
| 보안 헤더·쿠키 | CSP(script-src 'self', object-src 'none'), X-Frame-Options, nosniff, Permissions-Policy, no-store, HttpOnly·SameSite | 확인 |
| 정적 분석 | `bandit -r core views app.py cli.py config.py` | **High 0**. Medium 74: SQL 문자열 조립 경고(B608) 68건은 모두 고정 열 이름·`?` 자리표시 조각만 끼워 넣음(사용자 값은 매개변수) — 하나씩 확인. urlopen(B310)은 설정한 주소만, Markup(B704)은 이 프로그램이 만든 바코드 SVG(글자는 이스케이프) |
| 의존성 | `pip-audit -r requirements.lock` | flask 3.0.0·urllib3 2.7.0 취약점 → 3.1.3·2.8.0 으로 올림, **지금 0건** |

## 적용한 통제

- **인증**: 비밀번호 PBKDF2(60만 회), 5번 틀리면 잠금, IP 단위 차단, 비밀번호 바꾸면 이전 세션 무효, 무활동 로그아웃, 사내 SSO(OIDC+PKCE).
- **권한**: 역할 4단계 + 창고·플랜트 데이터 범위, 직무 분리(본인 거래 취소·본인 결재·요청자 발주 금지), 큰 실사 조정 결재.
- **입력**: 모든 SQL 매개변수 사용, CSRF 표, 같은 제출 두 번 처리 금지, 엑셀 수식 주입 방지, 압축 폭탄·행 수 제한, 업로드 형식 검사.
- **화면**: CSP(인라인 스크립트 금지), 클릭재킹 방지, 캐시 금지, 카메라는 이 사이트만(바코드 스캔).
- **기록**: 감사로그(DB 트리거로 수정·삭제 차단), 증빙 열람·엑셀 내보내기 기록, 거래는 고치지 않고 취소 거래로.
- **비밀값**: 환경변수로만(MM_SECRET_KEY, SMTP·네이버웍스 키, 감시 토큰). 저장소에 넣지 않는다.
- **시연 모드 주의**: `MM_DEMO=1` 이면 방문자가 시스템관리자가 된다 — 운영에서는 절대 켜지 않는다(서버 로그에 경고).

## 알려진 한계

- 감사로그는 같은 DB 안에 있다 → DB 관리자 권한이면 트리거를 끌 수 있다. 중요하면 표준출력 감사로그(`MM_AUDIT_STDOUT`)를 별도 로그 서버로 보낸다.
- 2단계 인증은 넣지 않았다(사용자 결정) → 사내 SSO 쪽 2단계 인증을 쓴다(`MM_SSO_REQUIRE_MFA=1`).
- 실제 SAP·ERP·메일·메신저 서버와는 연결 시험을 하지 않았다(가짜 서버로만 확인).

## 외부 점검 권고 범위

1. 인증 우회·세션 고정·비밀번호 재설정 흐름
2. 권한 상승(조회 → 관리자), 창고 범위 우회(IDOR) — 모든 번호가 들어가는 주소
3. 파일 업로드(엑셀·증빙·거래명세서 PDF·이미지) — 악성 파일, 경로 조작
4. 오프라인 대기열(`/transactions/queue`) 재전송·위조
5. ERP 수신·전송 경로, 감시 지표 접근 제어
6. 운영 환경 설정(HTTPS, 헤더, 쿠키 Secure, 서버 권한)
