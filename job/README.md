# 잡핏 — 채용공고 적합성 확인 (Flask)

여러 취업정보 사이트의 공고를 한곳에 모아 **지역·연봉·평균연봉·신입/경력**을 같은 기준으로 맞추고,
내 조건과 비교한 **적합성 점수**로 지원할 공고를 고른 뒤 **지원 현황**을 관리하는 개인용 도구입니다.

## 실행

```bash
pip install -r requirements.txt
python app.py            # http://127.0.0.1:5004
python -m pytest tests -q
```

**PC를 켜면 자동으로 켜기:** `start_app.ps1`이 앱을 화면 없이 켭니다(이미 켜져 있으면 그냥 끝, 남은 크롤링 잠금 정리).
Windows 작업 스케줄러에 로그인 때 실행하도록 `JobFit 앱 자동 시작` 작업으로 등록해 두었습니다.
끄기: 작업 관리자에서 python(app.py) 종료 또는 `Get-NetTCPConnection -LocalPort 5004 | % { Stop-Process -Id $_.OwningProcess }`.
기록: `data/app.log`, `data/app.err.log`.

키가 없어도 **공고 수집 → 샘플 공고 넣기**(가상 공고 40건)로 모든 화면을 둘러볼 수 있습니다.

## 사이트별 수집 방법

| 사이트 | 방법 | 설정 |
|---|---|---|
| 사람인 | 공식 Open API 자동 수집 · 링크 · CSV | `JOB_SARAMIN_KEY` (oapi.saramin.co.kr) |
| 고용24(워크넷) | 공식 Open API 자동 수집 | `JOB_WORK24_KEY` |
| 원티드 | 비공식 JSON 수집 · 링크 · CSV | `JOB_WANTED_ENABLED=1` (약관 확인 후) |
| 잡코리아 | 링크 · CSV | — |
| 링커리어 | 링크 · CSV | — |
| 자소설닷컴 | 링크 · CSV | — |
| 잡플래닛 | 링크 · CSV (평균연봉은 직접 입력) | — |
| 리멤버 | 링크 · CSV | — |

- **링크로 가져오기**: 공고 하나의 주소를 붙여 넣으면(첫 화면·목록 주소는 거부) 그 페이지 한 장만 읽어 JSON-LD `JobPosting`(구글 채용 검색용 데이터)을
  해석하고, 없으면 og:title/description 으로 채웁니다. 위 8개 사이트 도메인만 받습니다(다른 주소로 요청하지 않음).
  공개 API가 없는 사이트의 목록을 대량으로 긁지는 않습니다.
- **CSV·엑셀**: 열 `출처, 회사, 제목, 지역, 연봉, 경력, 학력, 고용형태, 마감일, 링크, 키워드, 직무, 회사평균연봉`
  (양식은 수집 화면에서 내려받기). UTF-8·CP949 모두 읽습니다.
- 같은 공고는 출처+공고번호(링크)로 합쳐져 여러 번 받아도 중복되지 않습니다.

## 정기 크롤링 (기본 4시간마다)

공고 수집 → **자동 수집**에서 켜고 검색어·사이트·간격을 정합니다. 앱이 켜져 있으면 안에서 돌고(`JOB_SCHEDULER=1`),
PC를 꺼 두는 경우에는 `python crawl.py`를 작업 스케줄러에 1시간마다 등록합니다(때가 된 경우에만 실행).
`python crawl.py --now`는 즉시 한 번, `--loop`는 계속 켜 두는 방식입니다. DB 잠금으로 여러 프로세스가 겹쳐 돌지 않습니다.

| 대상 | 방식 |
|---|---|
| 사람인·잡코리아·링커리어 (검색어 있음) | 검색어별 검색 결과 → 처음 보는 공고만 상세 읽기 |
| 사람인·잡코리아·링커리어 (검색어 없음 = 모든 직무) | 직무 분류를 하나씩 모두 돎 — 사람인 21·잡코리아 21·링커리어 14개. 새 공고는 직무마다 돌아가며 골라(사이트당 상한) 한 직무로 쏠리지 않음. 공고에 직무 이름을 붙이고, 세 직무 이상 목록에 똑같이 끼는 광고 공고는 직무를 비움. 사람인 근무지는 목록에서 채움 |
| 리멤버 | 사이트맵(전체 약 13,800건) 한 장을 매번 읽어 비교 → 새 번호만 상세 읽기, 빠진 번호는 요청 없이 마감 처리. 처음엔 최근 공고부터 한 번에 500건씩(약 25분) 채워 4~5일이면 전체 |
| 저장한 공고 | 마감 전 공고를 하루 한 번 다시 읽어 갱신, 404·410이면 마감 처리 (고용24·자소설닷컴·잡플래닛 링크 포함) |
| 사람인·고용24 API | 키가 있으면 같은 검색어로 함께 |

지키는 것: robots.txt 준수, 요청 사이 3초(`JOB_CRAWL_DELAY`), 한 번 실행이 다음 실행 전에 끝나도록 건수 제한,
403·429를 받으면 그 실행을 멈춤. 1만여 건을 매번 전부 다시 읽지 않습니다(3초 간격이면 11시간 이상 걸리고 차단 위험).
제외: 원티드(프로그램 요청 차단), 자소설닷컴·잡플래닛 목록(브라우저에서 그려져 목록 읽기 불가 — 링크 갱신만).

## 정규화

- 지역: `서울 > 강남구`, `경기도 성남시 분당구`, `전북특별자치도 …` → 시·도(짧은 이름) + 시군구. 재택·전국 구분.
- 연봉: `2,600~2,800만원`, `연봉 3,000만원 이상`, `월 250만원`, `시급 10,030원`, `4천5백만원`, `1억 2천만원` →
  연봉 만원 범위(월 ×12, 시급 ×209시간×12). `회사내규·면접 후 결정`은 '협의'로 두고 평균에서 뺍니다.
- 경력: 신입 / 경력(최소~최대 년) / 신입·경력 / 무관. 학력: 무관·고졸·초대졸·대졸·석사·박사.

## 적합성 (100점)

지역 25 + 연봉 25 + 경력 25 + 직무·기술 키워드 25. 학력 미달 −15, 고용형태 불일치 −10.
**지원 불가**(점수와 별도): 마감, 경력 2년 이상 부족(신입은 경력 요구 공고), 학력 미달, 제외 단어 포함.
80점↑ 적합 · 60↑ 보통 · 40↑ 낮음 · 그 밖 부적합.

## 평균 연봉

- 공고 평균: 연봉을 공개한 공고의 범위 가운데 값으로 지역별·신입/경력별·출처별·지역×경력 평균과 중앙값.
- 회사 평균연봉: 사이트 기업정보(국민연금 기준 추정)·잡플래닛 값을 공고 상세에서 직접 입력하거나 CSV `회사평균연봉` 열로.
- 공고 상세에서 이 공고 연봉을 같은 지역·같은 구분 평균과 비교합니다.

## 내 조건

희망 지역(비우면 전국), 신입/경력(**신입·경력 모두**를 고르면 경력으로 감점·지원 불가 표시를 하지 않음), 희망 최저 연봉(3,000~8,000만원, 500만원 단위),
희망 직무(19개 직무 + 세부 직무, 비우면 모든 직무), 보유 기술 키워드, 제외 단어. 직무·기술 점수는 희망 직무 일치와 기술 키워드 일치를 반반으로 계산합니다.

## 새로 들어온 맞는 공고

요약 화면 맨 위에 마지막 '모두 확인함' 이후 수집된 공고 중 지원 가능하고 적합도 80점 이상인 공고를 보여 줍니다.
공고 목록에는 NEW 표시와 '새 공고만' 필터가 있습니다. 평균 연봉 화면에는 500만원 단위 연봉 구간별 공고 수가 있습니다.

## 직무·세부 직무

사이트마다 다른 직무 이름(사람인 'IT개발·데이터', 잡코리아 'AI·개발·데이터', 링커리어 'IT/개발')을 하나의 직무로 묶었습니다
(`core/jobgroups.py`, 19개 직무). 공고 화면에서 직무를 고르면 그 직무의 세부 직무(예: IT → 백엔드·프론트엔드·데이터·AI·보안…)가
건수와 함께 나오고, 여러 개를 골라 볼 수 있습니다. 세부 직무는 제목·키워드의 단어로 판단하며, 어디에도 맞지 않으면 '기타·미분류'.
직무 이름이 없는 공고(리멤버 등)는 제목의 단어로 직무를 짐작합니다.

## 저장·자동 삭제

공고마다 **☆ 저장** 버튼이 있습니다. 저장한 공고는 마감돼도 지워지지 않고 **★ 저장한 공고**(상단 메뉴)에서 다시 볼 수 있습니다.
마감일이 지난 공고 중 저장하지 않았고 지원 기록도 없는 것은 자동으로 지웁니다(수집이 끝날 때마다, 그리고 한 시간마다).
지원 현황에 올린 공고는 기록을 잃지 않도록 지우지 않습니다.

## 지원 관리

자동 제출은 하지 않습니다. 원문 링크로 지원한 뒤 상태(관심 → 지원 예정 → 지원 완료 → 서류 합격 → 면접 → 최종 합격/불합격/포기),
지원일·다음 일정·메모를 기록하고 변경 이력을 남깁니다. 공고 목록은 CSV로 내보낼 수 있습니다(엑셀 수식 주입 방지).

## 구조

```

core/sources/  saramin · work24 · wanted · linkimport(링크) · fileimport(CSV·엑셀)

tests/  108개 (API 응답·페이지는 저장해 둔 fixture로, 네트워크 없이)
```

## 확인하지 못한 것

- 실제 API 키로 사람인·고용24 호출, 원티드 실 응답, 각 사이트 실제 공고 페이지의 JSON-LD 유무는 확인하지 않았습니다
  (저장한 예시 응답으로만 시험). 형식이 다르면 수집 기록에 오류가 남습니다.
- 사람인 `loc_mcd`·`exp_cd`, 고용24 지역 코드와 API 주소(`JOB_WORK24_URL`)는 문서 기준 값이라 실제와 다르면 바꿔야 합니다.
